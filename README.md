# Ниже света

Браузерная tower defense о подводной экспедиции. Удерживай грузовой лифт, пока к нему по руслу движутся стаи. Состав следующей волны показывает гидролокатор.

## Запуск

Открой `index.html` в Edge, Chrome или Firefox. Вся графика и логика входят в комплект. Для GitHub Pages подходит раздача статических файлов из корня репозитория.

## Кампания

| Район | Операции | Волн |
| --- | --- | --- |
| Базальтовый разлом | Первый спуск, Линь связи, Два притока | 12, 15, 18 |
| Затонувшая верфь | Чёрный ящик, Сухой док, Последний рейс | 14, 17, 20 |
| Стеклянная бездна | Холодный свет, Хрустальный свод, Ниже света | 16, 19, 24 |

После девяти операций и 155 волн открывается бесконечная вахта с отдельным рекордом.

## Оборона

1. Выбери орудие и нажми на свободную площадку. На старте один гарпун уже установлен.
2. Начни волну. Гарпун поражает переднюю цель в радиусе, минная башня атакует группу, криоизлучатель замедляет противников. Акустический импульс действует на всю стаю и снимает защиту левиафана.
3. Нажми на свою башню для улучшения. У каждой пять уровней и две специализации на выбор при переходе на третий уровень.
4. Трать образцы в лаборатории. Первая победа на каждой четвёртой волне операции приносит один образец, завершение операции приносит ещё два.

Клавиши 1–3 выбирают орудие. Пробел запускает волну или переключает паузу, Q активирует импульс. Скорость можно менять между ×1, ×2 и ×3.

Прогресс хранится в браузере для текущего адреса игры. Контрольная точка записывается перед волной и после её завершения. При возвращении посреди боя волна начинается с исходной расстановкой и запасом металла.

## Проверка боевой модели

При наличии Node.js выполни `node tests/campaign.cjs`. Тест проходит девять операций через обычные команды боевой модели, проверяет поражение, контрольные точки, повышение уровней, специализации и бесконечную вахту.
